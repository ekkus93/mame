# Repository guidance

## Code search and navigation

- When Serena is available and the project is activated, prefer its symbol-aware tools for code navigation and semantic searches, such as finding declarations, implementations, and references.
- Use Serena for source-code searches when its language understanding is useful; continue to use `rg` or `rg --files` for plain-text searches, file discovery, generated or unsupported files, and shell output.
- If Serena is unavailable, not initialized for this project, or does not cover the files being inspected, use `rg` and other standard repository tools.
